# Zn and Coated Material Fume Notes

Return to [[Laser Fume Extraction Overview]] · [[Technical Reference Index]]

> [!info] When to open this note
> Extra controls when cutting galvanized, zinc-coated, or painted sheet.

> [!danger] Zinc fume fever risk
> Zinc vaporizes before steel melts. Fine ZnO particulate is a serious occupational hazard. Extraction mandatory; enclosure closed.

## Mechanism

Galvanized (HDG/EG) sheet carries zinc coating. Laser vaporizes zinc at kerf → zinc-containing fume and fine deposits on filters, window, nozzle.

## Process notes

- N₂ preferred for edge quality but **does not eliminate** zinc fume
- Pierce especially violent — extra puffing may help window life
- See local commissioning card: [[Gweike 3015GAII 3 kW CypCut Cutting Parameter Setting#Current application — 1.2 mm galvanized sheet]]

## Extraction requirements

| Control | Action |
| --- | --- |
| Enclosure | Closed during cut |
| Fan | Running before pierce |
| Filters | Inspect more frequently; metal + zinc loading |
| Filter change | PPE; avoid shaking cartridges indoors |

## Exposure controls

- Workplace exposure assessment per local OSH (NZ: manage per HSNO/HSWA and SDS)
- Respiratory protection during filter service if assessment requires
- Local exhaust face velocity verified

## Cut quality vs health

Yellow edge on SS is gas purity; on galvanized, white/zinc smoke is fume — do not confuse.
