# Embedded Systems Practice Index

Return to the [[Embedded Systems Overview|subject overview]] · Follow the [[Embedded Systems Roadmap|course roadmap]].

The labs use the AUT AT90USB1287 board and `Labboard.h`. Full pasted source is indexed in the [[Lab Code Index]].

## Part A - Embedded C

- **Lab 1 - Digital I/O:** LEDs, toggle switches, debounced push-buttons, and the seven-segment display. Concepts: [[Microcontroller Operation and Architecture]] and [[Lab Board Knowledge]].
- **Lab 2 - Analogue and PWM:** speaker tones, potentiometer input, fan control, heater control, and display modes. Concept: [[Embedded Hardware Design]].
- **Lab 3 - LCD, Timers, and USART:** custom LCD characters, Timer0 interrupts, and command parsing. Concepts: [[Architectural Design]] and [[Embedded Digital Communications]].

## Part B - C# Applications

- **Lab 7 - Console OOP (Yahtzee):** dice, players, and scoring as C# classes. Concepts: [[Introduction to OOP and C Sharp]] and [[Classes Encapsulation and Constructors]].
- **Lab 8 - Windows Forms + Board:** a WinForms dice game driving board LEDs over USART. Concepts: [[GUI and Event-Driven Programming]] and [[File Handling and Serial Ports]].
