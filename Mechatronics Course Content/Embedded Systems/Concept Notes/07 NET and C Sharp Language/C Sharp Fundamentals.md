## Core Ideas

- Value types (`int`, `double`, `bool`, `char`) versus reference types; preferring `int` over `uint`.
- Methods: signatures, parameters, return types, and overloading.
- Arrays: declaration, indexing, iteration, and `foreach`.
- Control flow: `if`/`switch`, `for`/`while`/`do`, and expression evaluation.
- Course coding style: explicit curly braces rather than `=>` expression bodies; `System` namespace as the root library.
