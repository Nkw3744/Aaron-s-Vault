## Core Ideas

- Strings are immutable reference types; common methods, formatting, and `StringBuilder` for heavy concatenation.
- `struct` (value type) versus `class` (reference type) and when to choose each.
- Collections: `List<T>` for dynamic arrays and `Dictionary<TKey,TValue>` for key/value lookup.
- Generics (`<T>`) give type-safe, reusable containers.
- Includes an embedded review tying the C# data model back to the C side.
