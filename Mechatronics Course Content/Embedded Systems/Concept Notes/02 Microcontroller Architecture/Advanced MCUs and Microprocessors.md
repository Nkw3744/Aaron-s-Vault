# Advanced MCUs and Microprocessors

> [!info] Course navigation

## Core Ideas

- Microprocessor units (MPUs) run an operating system with external RAM/flash; MCUs are self-contained for dedicated tasks.
- Performance features on larger devices: instruction pipelines, caches, memory management units, and higher bus widths (16/32/64-bit).
- Trade-offs: MCUs win on cost, power, and boot time; MPUs win on throughput, memory, and software ecosystems.
- Device selection weighs I/O count, peripheral mix, memory, clock speed, power budget, and package.
