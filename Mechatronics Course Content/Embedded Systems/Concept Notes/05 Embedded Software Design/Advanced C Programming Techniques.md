## Core Ideas

- Pointers and pointer arithmetic; passing by reference and returning results via pointers.
- **Function pointers** for callbacks, jump tables, and event dispatch.
- Bit manipulation: masks, shifts, and `|= &= ^= ~` to set/clear/toggle/test register bits.
- The `volatile` qualifier for variables shared with ISRs or mapped to hardware registers.
- Fixed-point arithmetic and integer scaling where floating point is too costly.
- Structs, unions, and bitfields for compact data and register overlays.
