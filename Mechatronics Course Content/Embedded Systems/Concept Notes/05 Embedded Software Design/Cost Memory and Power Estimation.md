# Cost, Memory and Power Estimation

> [!info] Course navigation
> [[Embedded Systems Overview|Subject overview]] · [[Embedded Systems Roadmap|Course roadmap]] · [[Lecture-13.pdf|Lecture 13 overview]] · Previous: [[Software Architecture Case Study]] · Next: [[Introduction to OOP and C Sharp]]

## Core Ideas

- Estimating flash (code) and SRAM (data + stack) usage, and reading the map/size output of the toolchain.
- Power budgeting: active, idle, and sleep modes; average current and battery-life estimation.
- Cost estimation: bill of materials, unit cost versus volume, and non-recurring engineering cost.
- Design decisions balance performance, memory headroom, power, and cost against requirements.
