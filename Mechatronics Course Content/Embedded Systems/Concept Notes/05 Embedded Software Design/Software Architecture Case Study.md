## Core Ideas

- Worked case study: a **vineyard weather station** - a realistic sense/process/report embedded product.
- Turning requirements into an architecture: sensors, sampling, storage, and communications.
- Applying the earlier concepts together: modular drivers, a scheduler/state machine, power management, and a comms link.
- Design reasoning and trade-offs made explicit end to end.
