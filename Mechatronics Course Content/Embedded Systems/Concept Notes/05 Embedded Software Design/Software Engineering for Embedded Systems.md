# Software Engineering for Embedded Systems

> [!info] Course navigation
> [[Embedded Systems Overview|Subject overview]] · [[Embedded Systems Roadmap|Course roadmap]] · [[Lecture-08.pdf|Lecture 8 overview]] · Previous: [[Embedded Hardware Design]] · Next: [[Architectural Design]]

## Core Ideas

- Requirements capture: functional versus non-functional requirements, and traceability to tests.
- Lifecycle models: waterfall, V-model, and iterative/agile approaches, and where each fits embedded work.
- Design documentation: specifications, interface definitions, and version control.
- Verification and validation: unit testing, integration testing, and on-target testing.
- Quality and maintainability drivers unique to firmware: reliability, safety, and long field life.
