# Static, Inheritance and Polymorphism

> [!info] Course navigation
> [[Embedded Systems Overview|Subject overview]] · [[Embedded Systems Roadmap|Course roadmap]] · [[Lecture-16.pdf|Lecture 16 overview]] · Previous: [[Classes Encapsulation and Constructors]] · Next: [[Virtual Override Abstract and Sealed]]

## Core Ideas

- **Static members** belong to the class, not an instance ("called by the class"); static fields are shared across all objects.
- `const` and `readonly` for values that must not change.
- **Inheritance**: `class Derived : Base` reuses and extends a base class; C# allows only single inheritance.
- Windows Forms is inheritance you have already used - your form derives from `Form`.
- **Polymorphism**: the same call behaves differently depending on the runtime type of the object.
