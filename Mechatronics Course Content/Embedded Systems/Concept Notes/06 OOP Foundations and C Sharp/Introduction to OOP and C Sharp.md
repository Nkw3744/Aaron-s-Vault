## Core Ideas

- The four pillars of OOP: **abstraction, encapsulation, inheritance, and polymorphism** (Dr Banner's "class-oriented programming").
- A **class** is a blueprint; an **object** is an instance created with `new`.
- OOP suits host-side applications - GUIs, data logging, and hardware abstraction - where the embedded firmware stays in C.
- Modularity and reusability: objects bundle data with the behaviour that operates on it.
- Analogies from the course: abstraction (house/street/neighbourhood) and encapsulation (Rainbow's End wristband gateway).
