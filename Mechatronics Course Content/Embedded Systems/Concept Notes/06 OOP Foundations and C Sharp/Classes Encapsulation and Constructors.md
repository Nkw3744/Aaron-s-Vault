# Classes, Encapsulation and Constructors

## Core Ideas

- **Fields, properties, and methods**: properties (`get`/`set`) are gateways that guard private fields; the implicit `value` keyword sets them.
- **Access modifiers**: `private`, `public`, `protected`, `internal`; public fields are "global variables in disguise".
- **Constructors** share the class name and have no return type; default vs explicit vs overloaded constructors.
- Naming conventions: `PascalCase` for types and public members, `camelCase` for locals and parameters, prefixed private fields.
- The Circle-class evolution from public field to fully encapsulated get/set properties.
