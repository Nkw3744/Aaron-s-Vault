# File Handling and Serial Ports

> [!info] Course navigation
> [[Embedded Systems Overview|Subject overview]] · [[Embedded Systems Roadmap|Course roadmap]] · [[Lecture-22.pdf|Lecture 22 overview]] · [[Lecture-Week-11.pdf|Week 11 consolidation]] · Previous: [[GUI and Event-Driven Programming]]

## Core Ideas

- Streams and file I/O: `StreamReader`/`StreamWriter`, reading and writing text and CSV, and `using` for disposal.
- The `SerialPort` class: port name, baud rate, `DataReceived` events, and reading/writing bytes.
- Connecting the C# host to the AT90USB1287 over UART - the bridge between the two halves of the course.
- Parsing framed messages and handling partial/asynchronous data.
- Debugging serial links and basic graphics output.
