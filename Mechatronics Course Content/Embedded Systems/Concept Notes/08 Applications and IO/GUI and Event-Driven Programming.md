# GUI and Event-Driven Programming

> [!info] Course navigation

## Core Ideas

- Windows Forms: forms, controls (buttons, labels, text boxes, charts), and the designer versus code-behind.
- **Event-driven programming**: the message loop dispatches events to handlers (`Button_Click`, `Timer_Tick`).
- Delegates and event handlers wire UI actions to code.
- Keeping the UI thread responsive; using a `Timer` for periodic polling instead of blocking.
- Applied directly in the final-project GUI and the Lab 7/8 dice applications.
