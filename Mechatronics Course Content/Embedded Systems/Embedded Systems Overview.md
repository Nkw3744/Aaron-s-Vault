# Embedded Systems

ENEL712 is organized around durable concepts spanning embedded C and microcontrollers, followed by object-oriented C#/.NET host applications. Detailed lecture sequencing, labs, assessments, and hardware references live in focused secondary hubs.

> [!info] Start here
> [[Embedded Systems Roadmap|Course roadmap]] · [[Embedded Systems Practice Index|Labs and practice]] · [[Embedded Systems Assessment Index|Assessments]] · [[Embedded Systems Reference Index|References]]

## 1. Foundations

- [[Embedded Systems Foundations]] - embedded-system characteristics, constraints, real-time behaviour, and the development toolchain

## 2. Microcontroller Architecture

- [[Microcontroller Operation and Architecture]] - CPU, buses, registers, the fetch-decode-execute cycle, and peripherals
- [[MCU Memory Architecture and Clocking]] - Harvard vs von Neumann, flash/SRAM/EEPROM, clock sources, and prescalers
- [[Advanced MCUs and Microprocessors]] - MPUs vs MCUs, caches, pipelines, and device selection

## 3. Embedded Communications

- [[Embedded Digital Communications]] - UART, SPI, I2C, framing, baud rates, and serial-bus trade-offs

## 4. Embedded Hardware Design

- [[Embedded Hardware Design]] - schematics, power, decoupling, I/O interfacing, and design for manufacture

## 5. Embedded Software Design

- [[Software Engineering for Embedded Systems]] - requirements, lifecycle models, and documentation
- [[Architectural Design]] - superloops, state machines, scheduling, and event-driven design
- [[Modularizing Embedded Projects]] - headers, translation units, drivers, and hardware abstraction layers
- [[Advanced C Programming Techniques]] - pointers, bit manipulation, volatile, and fixed-point mathematics
- [[Software Architecture Case Study]] - vineyard weather-station worked example
- [[Cost Memory and Power Estimation]] - flash/SRAM budgeting, power modes, and bill-of-materials costing

## 6. OOP Foundations and C#

- [[Introduction to OOP and C Sharp]] - the four pillars, classes vs objects, and OOP for host applications
- [[Classes Encapsulation and Constructors]] - fields, properties, access modifiers, and constructors
- [[Static Inheritance and Polymorphism]] - static members, base/derived classes, and overriding
- [[Virtual Override Abstract and Sealed]] - virtual dispatch, abstract classes, interfaces, and sealing

## 7. .NET and C# Language

- [[The NET Framework and Memory Management]] - CLR, managed heap, garbage collection, and value/reference types
- [[C Sharp Fundamentals]] - syntax, types, methods, arrays, and control flow
- [[Strings Structures and Collections]] - strings, structs, lists, dictionaries, and generics

## 8. Applications and I/O

- [[GUI and Event-Driven Programming]] - Windows Forms, controls, events, and the message loop
- [[File Handling and Serial Ports]] - streams, file I/O, serial ports, and hardware-connected GUIs
