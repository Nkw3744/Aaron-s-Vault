## Core Ideas

- Differentiate the vector loop twice; each link gives a tangential term ($R\alpha$) and a normal/centripetal term ($R\omega^2$).
- Solve the four-bar for angular accelerations $\alpha_3$ and $\alpha_4$ (needs both position and velocity results).
- Compute point accelerations $\mathbf{a}_A$, $\mathbf{a}_B$, $\mathbf{a}_P$ via the relative-acceleration equation.
- Solve the slider-crank for $\alpha_3$ and slider acceleration $\ddot d$.
- Apply the Coriolis component $2\,\omega\,v_{\text{rel}}$ whenever a block slides along a rotating link.
